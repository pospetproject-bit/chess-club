# 🚀 Деплой «Шахматного Клуба» — инструкция для новичка

## Кто что делает

**Вы** (только это может сделать владелец аккаунтов — регистрация требует вашу почту/подтверждения):
1. Создаёте 3 бесплатных аккаунта: **GitHub**, **Render**, **Neon**.
2. Создаёте в каждом «ключ доступа» (токен) и присылаете их мне.
3. Делаете бота в Telegram по инструкции ниже (это вы хотели сами).

**Я** (всё техническое — сам, через API из моей среды):
- создаю репозиторий на вашем GitHub и загружаю туда весь код;
- создаю веб-сервис на Render (бесплатный тариф), настраиваю переменные, запускаю деплой;
- подключаю базу Neon, чтобы покупки и история не терялись;
- проверяю, что всё работает (сайт, API, WebSocket, платежи в демо-режиме);
- присылаю вам готовый HTTPS-адрес и точные значения для BotFather;
- после того как вы пришлёте токен бота — включаю боевой режим (Stars-платежи, бот).

> ⚠️ Почему я не могу зарегистрировать аккаунты сам: письма и коды подтверждения
> приходят на вашу почту/телефон, а платёжные данные (если сервис их спросит) —
> только ваши. Мне нужны не пароли, а **токены доступа** — их можно отозвать в любой момент.

Все три сервиса ниже — **бесплатные, без привязки карты** (проверено на 2026 год).

---

## Шаг 1. GitHub (хранилище кода) — 5 минут

1. Откройте https://github.com → **Sign up** (почта, пароль, имя пользователя).
   Подтвердите почту. Запомните свой **username**.
2. Создайте токен:
   - Нажмите на аватар (справа сверху) → **Settings**.
   - В левом меню внизу: **Developer settings**.
   - **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**.
   - Note: `chess-deploy`. Expiration: `30 days`.
   - Галочка: **repo** (полный блок «repo» — этого достаточно).
   - **Generate token** → скопируйте токен (начинается с `ghp_…`). Он показывается один раз!
3. **Пришлите мне:** ваш username + токен `ghp_…`.

Зачем: Render умеет деплоить прямо из Git-репозитория. Я создам репозиторий
`chess-club` (публичный — в коде нет секретов, все секреты живут только в
переменных Render) и загружу туда проект.

## Шаг 2. Render (бесплатный хостинг приложения) — 3 минуты

1. Откройте https://render.com → **Get Started** → **Sign in with GitHub**
   (разрешите доступ — это свяжет аккаунты).
2. Создайте API-ключ:
   - Аватар справа сверху → **Account Settings**.
   - В меню: **API Keys** → **Create API Key**.
   - Имя: `chess-deploy` → скопируйте ключ (начинается с `rnd_…`).
3. **Пришлите мне:** ключ `rnd_…`.

Что я сделаю: создам веб-сервис на тарифе **Free** (512 МБ, 750 часов/месяц —
хватает на один сервис 24/7), команда сборки `npm ci --omit=dev`, запуск
`node server/index.js`, HTTPS-адрес вида `https://chess-club-xxxx.onrender.com`.

## Шаг 3. Neon (бесплатная база данных) — 3 минуты

Зачем: на бесплатном Render диск «временный» — при перезапуске файлы стираются.
Без внешней базы покупки и история партий исчезали бы. Neon — вечный бесплатный
Postgres (1 ГБ, без карты, без ограничения по времени).

1. Откройте https://neon.com → **Sign up** (через GitHub/Google или почту).
2. **Create project**: имя `chess-club`, регион ближайший к вам
   (например `Europe (Frankfurt)`), версия Postgres — по умолчанию.
3. На дашборде проекта найдите панель **Connection Details / Connection string**
   и скопируйте строку вида:
   `postgresql://neondb_owner:****@ep-xxxx.pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require`
4. **Пришлите мне:** эту строку целиком.

Я задам её как `DATABASE_URL` — приложение само создаст таблицу и будет хранить
всё в Neon (проверено тестами: данные переживают рестарты).

## Шаг 4. Telegram (делаете вы, после моего деплоя) — 10 минут

Всё в чате с **[@BotFather](https://t.me/BotFather)** (официальный бот Telegram, синяя галочка).

### 4.1. Создаём бота
1. Напишите `/newbot`.
2. BotFather спросит **имя** (отображаемое): `Шахматный Клуб`.
3. Спросит **username** (латиница, должен заканчиваться на `bot`):
   например `my_chess_club_bot` (если занят — попробуйте другой).
4. В ответ придёт сообщение с **токеном** вида `123456789:AAF…xyz`.
   ⚠️ Это секрет — никому не публикуйте. **Пришлите его мне** (я включу боевой
   режим сам) — или вставьте сами: Render → Dashboard → ваш сервис →
   **Environment** → добавить переменную `BOT_TOKEN` → **Save Changes**
   (сервис перезапустится сам).

### 4.2. Создаём мини-апп (само приложение внутри Telegram)
1. Напишите `/newapp`.
2. Выберите вашего бота из списка.
3. **Title**: `Шахматный Клуб`.
4. **Short description**: `Шахматы с ботом и друзьями: уроки, задачи, разбор партий`.
5. **Photo**: попросит картинку 640×360 — отправьте любое подходящее изображение
   (можно скриншот доски из `shots/game.png`, обрезав до нужного формата).
6. **Demo URL / Web App URL**: вставьте адрес, который я вам пришлю,
   например `https://chess-club-xxxx.onrender.com`.
7. **Short name**: `play` (или любое латинское слово).
8. Готово! BotFather пришлёт ссылку вида `https://t.me/my_chess_club_bot/play`.
9. **Пришлите мне:** short name (`play`) — я задам `APP_SHORT_NAME`, чтобы
   приглашения друзьям вели đúng… (правильно) прямо в приложение.

### 4.3. Оформление (необязательно, но красиво)
- `/setdescription` — текст, который видят до запуска бота (возьмите из README).
- `/setabouttext` — короткое «Шахматы в Telegram: бот, друзья, уроки».
- `/setuserpic` — аватар бота (подойдёт `shots/home.png` или любой шахматный арт).
- Кнопка меню «♟ Играть» бот установит **сам** при запуске (`setChatMenuButton`).

### 4.4. Проверка
1. Откройте бота → нажмите **Start** → кнопка «♟ Открыть Шахматный Клуб».
2. Сыграйте партию, купите что-нибудь за ⭐ (Stars списываются с вашего баланса;
   новые аккаунты могут купить звёзды прямо в Telegram: Настройки → Telegram Stars).
3. `/paysupport` и `/terms` уже работают (требование Telegram для цифровых товаров).
   Задайте `TERMS_URL` (любая страница с условиями, можно Telegraph-статью) и
   `SUPPORT_USERNAME` (ваш username для поддержки) — пришлите мне, я добавлю.

## Шаг 6. Чтобы сервер не «засыпал» (бесплатный лайфхак)

Бесплатный Render засыпает после **15 минут** без запросов; первый запрос после
сна будит сервис ~30–60 секунд. Для игры с друзьями это неприятно. Решение —
бесплатный «будильник»:

1. https://cron-job.org → Sign up (почта, бесплатно, без карты).
2. **Create cronjob**:
   - Title: `chess-keepalive`
   - URL: `https://ваш-сервис.onrender.com/healthz`
   - Schedule: каждые **10 минут** (Every 10 minutes).
3. Save. Готово — сервис всегда бодрый, и это укладывается в бесплатные 750 часов/мес.

## Limits бесплатных тарифов (честно)

| Сервис | Бесплатно | Ограничение |
|---|---|---|
| Render | 750 ч/мес, 512 МБ | сон после 15 мин простоя (лечится шагом 6); при превышении часов сервис приостановится до следующего месяца |
| Neon | 1 ГБ, вечный free | Compute «засыпает» после простоя — первый запрос на 1–3 с дольше |
| GitHub | публичные/приватные репо | практически без ограничений для нашего размера |
| cron-job.org | бесплатно | — |
| Adsgram | доход с рекламы | нужен трафик для выплат |

Когда проект вырастет: Render Starter $7/мес (без сна) + Neon Launch — всё
остальное в коде менять не нужно, только тарифы.

## Альтернатива: если не хотите давать мне токены

Можно всё сделать самому за 10 кликов: загрузите код в свой GitHub-репозиторий
(или попросите меня прислать архив), затем Render → **New +** → **Blueprint** →
выберите репозиторий → Render прочитает `render.yaml` и создаст сервис сам.
Останется вписать переменные (`DATABASE_URL`, `BOT_TOKEN`, `WEBAPP_URL`,
`APP_SHORT_NAME`) в разделе Environment. Но вариант с токенами проще для новичка —
всю рутину сделаю я.
